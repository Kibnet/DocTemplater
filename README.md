# DocTemplater

Десктопное приложение для заполнения шаблонов DOCX файлов с поддержкой плейсхолдеров.

## Описание

DocTemplater - это приложение на базе AvaloniaUI, которое позволяет:
- Выбирать шаблоны DOCX из папки Templates
- Автоматически извлекать плейсхолдеры из документов
- Заполнять значения в удобной форме с предпросмотром
- Генерировать готовые документы
- Сохранять и редактировать значения для повторного использования без создания документа
- Открывать активный каталог шаблонов в системном файловом менеджере

## Формат плейсхолдеров

Плейсхолдеры в документах должны иметь следующий формат:

```
{НазваниеПлейсхолдера:Тип(СтрокаФормата)}
```

### Поддерживаемые типы:

1. **String** - текстовая строка
   - Пример: `{Имя:String()}`

2. **Integer** - целое число
   - Пример: `{Количество:Integer()}`
   - С форматом: `{Сумма:Integer(N0)}`

3. **DateTimeOffset** - дата и время
   - Пример: `{ДатаНачала:DateTimeOffset(d MMMM yyyy)}`
   - Форматы: `d`, `D`, `dd.MM.yyyy`, `d MMMM yyyy` и т.д.

### Примеры плейсхолдеров:

```
{ИмяКлиента:String()}
{НомерДоговора:Integer()}
{ДатаПодписания:DateTimeOffset(d MMMM yyyy)}
{Сумма:Integer(N0)}
{СрокДействия:DateTimeOffset(dd.MM.yyyy)}
```

## Использование

1. Поместите DOCX файлы с плейсхолдерами в `%APPDATA%\DocTemplater\Templates` или выберите свою папку кнопкой `...`
2. Запустите приложение
3. Выберите шаблон из списка
4. Заполните все поля формы
5. Просмотрите превью форматированных значений
6. Укажите путь для сохранения готового документа
7. Нажмите «Сохранить документ» для создания DOCX.

Чтобы исправить сохранённые значения, выберите шаблон, измените поля и нажмите «Сохранить значения». Документ при этом не создаётся; изменения загрузятся при следующем открытии этого шаблона. Выходной каталог и шаблон имени документа этим действием не изменяются.

Если после сохранения снова изменить поле, сообщение «Есть несохранённые изменения» напомнит, что нужно ещё раз нажать «Сохранить значения».

Кнопка «Открыть папку» рядом с путём шаблонов открывает активный каталог в файловом менеджере. Выбор отдельного шаблона не требуется. Кнопка `...` по-прежнему служит для смены каталога. Если вручную набранный путь не существует, активным остаётся прежний каталог; его путь показан в подсказке кнопки открытия.

## Установка и обновления (Windows x64)

Скачайте `DocTemplater-win-Setup.exe` из [последнего релиза](https://github.com/Kibnet/DocTemplater/releases/latest). Установщик включает .NET Runtime и устанавливает приложение для текущего пользователя. Установщик пока не подписан; Windows может показать SmartScreen. Контрольные суммы файлов опубликованы в `SHA256SUMS.txt`.

Установленная версия сама проверяет GitHub и скачивает обновление. Кнопки и текущая версия находятся внизу окна. После скачивания нажмите «Установить и перезапустить». Если в форме есть несохранённые изменения, можно вернуться к документу или явно обновить без сохранения. Ошибка сети не мешает заполнению документов; проверку можно повторить вручную. В запуске из `bin` обновления отключены.

Настройки хранятся в `%APPDATA%\DocTemplater\settings.json`; пользовательские каталоги должны находиться вне установки. При первом переходе со старой версии закройте её до запуска Setup. Известные шаблоны рядом с текущим EXE копируются с сохранением оригиналов, при изменении путей создаётся backup настроек. Дополнительные резервные копии файлов внутри установки и manifest их исходных имён находятся в `%APPDATA%\DocTemplater\UpdateBackups`. При конфликте можно выбрать внешний каталог на экране восстановления. Для невалидного settings.json сначала восстановите файл из резервной копии.

Если шаблоны остались в другой распакованной копии приложения, выберите ту папку кнопкой `...`. Автоматического поиска по диску нет. Старую копию удаляйте только после проверки файлов.

Для выпуска: SDK указан в `global.json`, `dotnet tool restore`, затем `./scripts/Build-Release.ps1 -Version 0.1.0`. Выходной каталог должен быть новым и находиться под `artifacts/`. Workflow `Release` на теге `vX.Y.Z` выполняет Debug/Release build и tests, упаковывает приложение, проверяет загруженные assets и публикует полный GitHub Release. Версия в csproj и `releases/X.Y.Z.md` должны соответствовать тегу.

## Функции

- ✅ Автоматическое обнаружение шаблонов в папке Templates
- ✅ Извлечение плейсхолдеров с использованием регулярных выражений
- ✅ Динамическая генерация формы ввода на основе типов данных
- ✅ Превью форматированных значений в реальном времени
- ✅ Валидация введенных данных
- ✅ Сохранение значений для каждого шаблона
- ✅ Автоматическое открытие документа после сохранения (опционально)
- ✅ Поддержка культуры ru-RU для форматирования

## Технологии

- **.NET 9.0**
- **AvaloniaUI 11.3.8** - кроссплатформенный UI framework
- **ReactiveUI** - MVVM и реактивное программирование
- **DocumentFormat.OpenXml** - работа с DOCX файлами
- **System.Text.Json** - сериализация данных

## Структура проекта

```
DocTemplater/
├── Domain/              # Доменные модели
├── Services/            # Бизнес-логика
├── ViewModels/          # ViewModels (MVVM)
├── Views/               # UI представления (XAML)
└── Templates/           # Папка для шаблонов DOCX
```

## Сборка и запуск

```bash
# Восстановить зависимости
dotnet restore

# Собрать проект
dotnet build

# Запустить приложение
dotnet run --project DocTemplater/DocTemplater.csproj
```

## Примечания

- Приложение автоматически создает папку `Templates` при запуске
- Настройки и сохранённые значения хранятся в `%APPDATA%/DocTemplater/settings.json`
- Для каждого имени файла шаблона хранится один набор значений. При правке сохраняются также ранее записанные поля, которых сейчас нет в DOCX
- Приложение поддерживает культуру ru-RU для корректного форматирования дат и чисел
