## DocTemplater 0.1.0 — Windows x64

- Автоматическая проверка и скачивание обновлений из GitHub. Установка готового обновления — по кнопке с перезапуском.
- Подтверждение перед потерей несохранённых значений и настроек выходного файла.
- Постоянный каталог шаблонов в `%APPDATA%\DocTemplater\Templates`; перенос известных данных из каталога установки с сохранением оригиналов и резервной копии настроек.
- Защита профиля от одновременного открытия несколькими копиями приложения.
- Редактирование сохранённых значений отдельно от создания документа и кнопка открытия папки шаблонов.

### Установка

Скачайте `DocTemplater-win-Setup.exe` и запустите его. Установщик включает .NET Runtime; отдельная установка .NET не требуется. Закройте старую копию приложения перед установкой. Установщик не подписан: Windows может показать предупреждение SmartScreen.

Настройки сохраняются в `%APPDATA%\DocTemplater\settings.json`. Если шаблоны остались в старой распакованной копии, выберите их папку кнопкой `…`. Не удаляйте старую копию до проверки переноса. При ошибке чтения настроек или конфликте файлов приложение останавливает запуск и сохраняет исходные данные.

Для проверки скачанных файлов используйте `SHA256SUMS.txt`. `*-Portable.zip` — дополнительная переносная сборка; для обычной установки и автоматических обновлений используйте Setup.exe.
